
# KnightGame

KnightGame is a 2D, Pixelated Platformer Game made using Godot Engine.

In this Game, The player is a Knight and the Knight has to beat 5 levels while slaying enemies to get to the end and win the game.
There is a Tutorial Level and 4 Other Levels in which you can play.
There is a Level Selection Scene where only if you beat the previous levels, then only are you allowed to move to the next Level. For example, if you are on level 1, only after beating level 1 are you able to move to level 2.

This game has mobile controls! Here are the PC Controls for this game:

Arrow Keys/A & D - Left and Right Movement
Space - Jump
Q - Attack/Swing Sword
